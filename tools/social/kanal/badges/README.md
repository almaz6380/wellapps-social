# Store-Badges

Die offiziellen Knöpfe von Apple und Google, wie sie im Abspann der Reels und
in den Bildposts erscheinen.

⚠ **Nicht nachzeichnen, nicht verzerren, nicht animieren.** Beide Richtlinien
untersagen jede Veränderung. Deshalb steht im Reel-Template ausdrücklich, dass
die Badges — anders als die Textpille daneben — **nicht pochen** dürfen, und
die Höhe ist fest, während die Breite sich aus dem Bild ergibt.

⚠ **Nur zeigen, wo es die App wirklich gibt.** Die Wahrheit steht in
`tools/social/apps.json` unter `stores`; ein Badge für einen Store ohne App
ist eine Falschaussage im Video.

Dieselben Dateien liegen in `anigosha/tools/reels/spot/badges/` (der
Werbespot) und `mypeak/scripts/badges/` (FullReps Bildposts). Kopien, weil die
drei Repos unabhängig voneinander rendern.
